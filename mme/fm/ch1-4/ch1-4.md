# 期权的概念与二项式定价模型

## 一、期权的概念

### 问1. 期权的基本分类与权利

**问题：** 
请简述买入期权（看涨期权）与卖出期权（看跌期权）在赋予持有者的权利上有什么本质区别？并说明欧式期权与美式期权在行权时间上的核心差异。

<details>
<summary>解答：</summary>

买入期权（看涨期权）赋予持有者在特定时间或之前按约定价格买入标的资产的权利，而卖出期权（看跌期权）赋予持有者按约定价格卖出标的资产的权利。两者的本质区别在于对标的资产未来价格走势的预期方向不同。

在行权时间上，欧式期权只允许在到期日当天行使权利，而美式期权允许持有者在购买后至到期日之间的任何时刻行使权利。这种灵活性使得美式期权在定价时通常需要比同等条件的欧式期权更高的价值。

</details>

### 问2. 期权内在价值与状态判断

**问题：** 
假设某标的股票当前市场价格为100元，某看涨期权的施权价为90元。请计算该期权的内在价值，并判断该期权处于何种状态（币内、币上或币外）。

<details>
<summary>解答：</summary>

对于看涨期权而言，内在价值的计算公式为 $\max(S - E, 0)$，其中 $S$ 为标的资产市场价，$E$ 为施权价。代入题目数据，内在价值为 $\max(100 - 90, 0) = 10$ 元。

根据期权状态的定义，当看涨期权的标的资产市场价大于施权价（即 $S > E$）时，该期权具有正的内在价值，此时该期权处于“币内”（in the money）状态。

</details>

### 问3. 欧式期权平价公式的理解

**问题：** 
请写出欧式看涨期权与看跌期权的平价公式，并简要解释为什么在不存在套利机会的市场中，该公式必须成立。

<details>
<summary>解答：</summary>

欧式期权的平价公式为 $C - P = S - Ee^{-rt}$，其中 $C$ 为看涨期权价格，$P$ 为看跌期权价格，$S$ 为股票现价，$E$ 为施权价，$r$ 为无风险利率，$t$ 为距到期时间。

该公式成立的根本原因是无套利原则。通过构建一个包含买入看涨期权、卖出看跌期权、买入股票和借入现金的组合，可以证明该组合在到期日的价值恒为零。如果期初该组合的价值不为零，市场参与者就可以通过构建相反的头寸获取无风险套利利润，这种套利行为会迅速促使价格回归到平价公式所规定的均衡状态。

</details>

### 问4. 期权价格对标的资产价格的依赖性

**问题：** 
根据期权定价理论，当标的资产价格 $S$ 上升时，欧式看涨期权和欧式看跌期权的价格将分别如何变化？请说明它们的价格关于 $S$ 具有怎样的数学性质。

<details>
<summary>解答：</summary>

当标的资产价格 $S$ 上升时，欧式看涨期权的价格会随之上升（非减函数），因为标的资产越贵，以固定施权价买入的权利就越有价值；相反，欧式看跌期权的价格会随之下降（非增函数），因为以固定价格卖出的权利变得不那么有价值了。

在数学性质上，无论是看涨还是看跌期权，其价格关于标的资产价格 $S$ 都是凸函数。这意味着期权价格对 $S$ 的变化率（即Delta）是单调递增的，反映了期权收益的非线性特征。

</details>

### 问5. 美式看涨期权提前行权的条件

**问题：** 
在不支付红利的情况下，美式看涨期权与欧式看涨期权的价格有何关系？为什么理性的投资者通常不会在到期前提前行使不支付红利股票的美式看涨期权？

<details>
<summary>解答：</summary>

在不支付红利的情况下，美式看涨期权的价格等于欧式看涨期权的价格，即 $C^A = C^E$。

理性的投资者不会提前行权，是因为提前行权意味着放弃了期权剩余的时间价值。此外，即使当前股票价格高于施权价，投资者完全可以通过在市场上直接卖出该看涨期权来获取不低于立即行权收益的金额。由于提前行权不仅丧失了时间价值，还放弃了继续享受股价上涨的潜在收益，因此在无红利情况下提前行权是不理性的。

</details>

### 问6. 单期二叉树模型中的无套利条件

**问题：** 
在单期二项式期权定价模型中，设无风险利率为 $r_f$，股票上涨倍数为 $u$，下跌倍数为 $d$。为了防止市场出现无风险套利机会，参数 $u$、$d$ 和 $r_f$ 之间必须满足什么数学关系？

<details>
<summary>解答：</summary>

为了防止市场出现无风险套利机会，必须满足 $u > 1 + r_f > d$。这一条件确保了无风险收益率严格介于股票可能的最高收益率和最低收益率之间。

如果 $1 + r_f \ge u$，投资者可以通过借入无风险资金买入股票来获取无风险利润；反之，如果 $1 + r_f \le d$，投资者可以通过卖空股票并将资金存入无风险账户来套利。只有在上述不等式成立时，市场才是无套利的，风险中性概率 $p_* = \frac{1+r_f-d}{u-d}$ 才会落在 $(0, 1)$ 的有效概率区间内。

</details>

## 二、期权相关的数学与统计知识

### 问7. 风险中性概率的统计学意义

**问题：** 
在二叉树模型中，我们使用风险中性概率 $p_*$ 来计算期权的期望收益并折现。请解释 $p_*$ 与股票实际上涨概率 $q$ 的区别，以及为什么可以使用 $p_*$ 进行定价。

<details>
<summary>解答：</summary>

股票实际上涨概率 $q$ 反映了投资者对股票未来走势的真实预期，通常包含了股票的风险溢价；而风险中性概率 $p_*$ 是一个人为构造的数学概率，它使得股票在风险中性世界中的期望收益率恰好等于无风险利率 $r_f$。

可以使用 $p_*$ 进行定价的原因在于无套利定价原理。期权的价格可以通过构建一个由标的股票和无风险资产组成的复制组合来确定，该组合的构建成本与投资者的风险偏好无关。因此，期权的当前价格等于其在风险中性概率分布下的期望未来收益按无风险利率折现的现值。

</details>

### 问8. 多期二叉树的二项分布特征

**问题：** 
在 $N$ 期二叉树模型中，如果股票经历了 $n$ 次上涨和 $N-n$ 次下跌，请写出到期日期权价值的期望表达式，并说明其中涉及的概率分布名称及其公式。

<details>
<summary>解答：</summary>

在 $N$ 期模型中，期权在初始时刻的价格等于到期日各种可能状态下期权价值的期望按无风险利率折现。其表达式包含了对所有可能上涨次数 $n$ 的求和，每一项都对应着特定的股票终端价格和期权回报。

该模型中涉及的概率分布是二项分布 $B(n \mid N, p_*)$。其公式为 $\frac{N!}{n!(N-n)!} p_*^n (1-p_*)^{N-n}$，表示在 $N$ 次独立试验中恰好发生 $n$ 次上涨（成功）的概率。正是由于这一二项分布特征，该定价模型被称为“二项式期权定价模型”。

</details>

## 三、二叉树模型的编程实验

### 问9. 二叉树定价Python代码的参数映射

**问题：** 
在使用Python实现二叉树期权定价时，若已知标的资产当前价格 $S_0$、年化波动率 $\sigma$、无风险年利率 $r$ 和到期时间 $T$，请写出计算单步时间长度 $\Delta t$、上涨因子 $u$ 和下跌因子 $d$ 的代码表达式。

<details>
<summary>解答：</summary>

首先需要将总时间 $T$ 划分为 $N$ 个步长，单步时间长度计算为 `delta_t = T / N`。这是将连续时间离散化的基础步骤。

接着，根据Cox-Ross-Rubinstein (CRR) 模型，上涨因子和下跌因子的代码表达式分别为 `u = math.exp(sigma * math.sqrt(delta_t))` 和 `d = 1 / u`（或 `d = math.exp(-sigma * math.sqrt(delta_t))`）。这种参数设定保证了当步数 $N$ 趋于无穷大时，二叉树模型会收敛于Black-Scholes-Merton模型。

</details>

### 问10. 美式期权二叉树回溯算法的逻辑

**问题：** 
在编写美式期权的二叉树定价程序时，从到期日向前回溯计算节点期权价值的核心逻辑是什么？请用文字或伪代码描述这一判断过程。

<details>
<summary>解答：</summary>

美式期权可以在到期前的任何节点行权，因此在回溯计算时，每个节点的期权价值必须比较“立即行权的内在价值”与“继续持有的期望折现价值”。

核心逻辑可以描述为：对于当前节点，首先计算其内在价值（看涨期权为 $\max(S - E, 0)$，看跌期权为 $\max(E - S, 0)$）；然后计算继续持有价值，即 `exp(-r * delta_t) * (p * V_up + (1-p) * V_down)`；最后，当前节点的期权价值取这两者中的较大值，即 `V_current = max(内在价值, 继续持有价值)`。

</details>

### 问11. 二叉树期权定价模型的Python编程实现

**问题：**
请编写一个完整的Python程序，实现考克斯-罗斯-鲁宾斯坦（Cox-Ross-Rubinstein）二叉树期权定价模型。程序需包含两个核心功能：一是构建并打印股票价格的二叉树路径；二是通过风险中性概率倒推计算欧式看涨期权的当前价值。假设参数为：初始股价 $S_0=100$，施权价 $E=105$，无风险利率 $r=0.05$，上涨因子 $u=1.1$，下跌因子 $d=0.9$，步数 $N=3$。


<details>
<summary>解答：</summary>

**1. 编程思路与数学原理：**
二叉树模型的核心在于离散化资产价格路径并利用无套利定价原理。
首先，我们需要定义风险中性概率 $p_* = \frac{(1+r) - d}{u - d}$。在本题中，$(1.05 - 0.9) / (1.1 - 0.9) = 0.75$。
其次，构建股票价格树：在第 $i$ 步第 $j$ 个节点（$j$ 代表上涨次数），股价为 $S_{i,j} = S_0 \cdot u^j \cdot d^{i-j}$。
最后，进行期权价值倒推：
- **终端条件（$t=N$）：** 欧式看涨期权价值 $C_{N,j} = \max(S_{N,j} - E, 0)$。
- **递推公式（$t < N$）：** $C_{i,j} = \frac{1}{1+r} [p_* C_{i+1, j+1} + (1-p_*) C_{i+1, j}]$。

**2. Python代码实现：**

```python
import numpy as np

def binomial_option_pricing(S0, E, r, u, d, N):
    """
    CRR二叉树期权定价模型
    :param S0: 初始股价
    :param E: 施权价
    :param r: 无风险利率 (单期)
    :param u: 上涨因子
    :param d: 下跌因子
    :param N: 时间步数
    """
    
    # 1. 计算风险中性概率
    p_star = ((1 + r) - d) / (u - d)
    print(f"风险中性概率 p*: {p_star:.4f}")
    
    # 2. 构建股票价格树 (使用二维列表或数组)
    # stock_tree[i][j] 表示第 i 步，经历了 j 次上涨后的股价
    stock_tree = []
    for i in range(N + 1):
        level = []
        for j in range(i + 1):
            price = S0 * (u ** j) * (d ** (i - j))
            level.append(price)
        stock_tree.append(level)
        
    print("\n--- 股票价格二叉树 ---")
    for i, level in enumerate(stock_tree):
        print(f"t={i}: {[f'{p:.2f}' for p in level]}")

    # 3. 初始化期权价值树 (从最后一步开始)
    # option_tree[i][j] 对应 stock_tree[i][j] 处的期权价值
    option_tree = [[0.0] * (i + 1) for i in range(N + 1)]
    
    # 设置终端价值 (t=N)
    for j in range(N + 1):
        option_tree[N][j] = max(stock_tree[N][j] - E, 0)
        
    # 4. 向后倒推计算期权价值
    for i in range(N - 1, -1, -1):
        for j in range(i + 1):
            # 期望值折现
            expected_val = p_star * option_tree[i+1][j+1] + (1 - p_star) * option_tree[i+1][j]
            option_tree[i][j] = expected_val / (1 + r)
            
    print("\n--- 期权价值二叉树 (倒推结果) ---")
    for i, level in enumerate(option_tree):
        print(f"t={i}: {[f'{v:.4f}' for v in level]}")
        
    return option_tree[0][0]

# --- 主程序执行 ---
if __name__ == "__main__":
    # 题目给定参数
    S0 = 100
    E = 105
    r = 0.05
    u = 1.1
    d = 0.9
    N = 3
    
    print(f"参数设定: S0={S0}, E={E}, r={r}, u={u}, d={d}, N={N}\n")
    
    final_price = binomial_option_pricing(S0, E, r, u, d, N)
    
    print(f"\n>>> 最终计算结果: 该欧式看涨期权的当前价值为 {final_price:.4f} <<<")
```

**3. 结果分析：**
运行上述代码，程序将输出每一步的股价分布和对应的期权价值。
- 在 $t=3$ 时，只有当股价上涨次数较多（如 $uuu, uud$ 等组合导致股价超过105）时，期权才有价值。
- 随着步数倒推回 $t=0$，未来的不确定性被风险中性概率加权并折现，最终得到的 $t=0$ 时刻的值即为理论定价。
- 对于本例参数，计算结果应约为 **6.38** 左右（具体取决于浮点数精度），这展示了如何通过简单的离散模型逼近连续时间的期权定价逻辑。

**4. 输出结果：**

### 问12. 美式期权二叉树定价模型的Python编程实现

**问题：**
在欧式期权的基础上，请编写一个完整的Python程序，实现美式看跌期权（American Put Option）的二叉树定价模型。美式期权允许在到期前的任何节点提前行权。假设参数为：初始股价 $S_0=100$，施权价 $E=110$，无风险利率 $r=0.05$，上涨因子 $u=1.1$，下跌因子 $d=0.9$，步数 $N=3$。程序需通过风险中性概率倒推计算期权价值，并在每个节点判断是否提前行权。

<details>
<summary>解答：</summary>

**1. 编程思路与数学原理：**
与欧式期权不同，美式期权在每一个中间节点都面临一个选择：是立即行权获取内在价值，还是继续持有等待未来的潜在收益。
- **内在价值计算：** 对于看跌期权，在当前节点股价为 $S$ 时，立即行权的收益为 $\max(E - S, 0)$。
- **继续持有价值：** 使用风险中性概率 $p_*$ 计算未来期望收益并折现：$V_{hold} = \frac{1}{1+r} [p_* V_{up} + (1-p_*) V_{down}]$。
- **节点价值更新：** 当前节点的期权价值必须取两者中的较大值，即 $V_{current} = \max(\text{内在价值}, V_{hold})$。

**2. Python代码实现：**

```python
def american_put_binomial(S0, E, r, u, d, N):
    """
    美式看跌期权二叉树定价模型
    """
    # 1. 计算风险中性概率
    p_star = ((1 + r) - d) / (u - d)
    print(f"风险中性概率 p*: {p_star:.4f}")
    
    # 2. 构建股票价格树
    stock_tree = []
    for i in range(N + 1):
        level = []
        for j in range(i + 1):
            price = S0 * (u ** j) * (d ** (i - j))
            level.append(price)
        stock_tree.append(level)
        
    print("\n--- 股票价格二叉树 ---")
    for i, level in enumerate(stock_tree):
        print(f"t={i}: {[f'{p:.2f}' for p in level]}")

    # 3. 初始化期权价值树
    option_tree = [[0.0] * (i + 1) for i in range(N + 1)]
    
    # 设置终端价值 (t=N)，此时必须行权或作废
    for j in range(N + 1):
        option_tree[N][j] = max(E - stock_tree[N][j], 0)
        
    # 4. 向后倒推计算期权价值 (核心修改点)
    for i in range(N - 1, -1, -1):
        for j in range(i + 1):
            # 计算继续持有的期望折现价值
            expected_val = p_star * option_tree[i+1][j+1] + (1 - p_star) * option_tree[i+1][j]
            hold_value = expected_val / (1 + r)
            
            # 计算立即行权的内在价值
            exercise_value = max(E - stock_tree[i][j], 0)
            
            # 美式期权取两者的较大值
            option_tree[i][j] = max(hold_value, exercise_value)
            
    print("\n--- 美式看跌期权价值二叉树 (倒推结果) ---")
    for i, level in enumerate(option_tree):
        print(f"t={i}: {[f'{v:.4f}' for v in level]}")
        
    return option_tree[0][0]

# --- 主程序执行 ---
if __name__ == "__main__":
    # 题目给定参数
    S0 = 100
    E = 110
    r = 0.05
    u = 1.1
    d = 0.9
    N = 3
    
    print(f"参数设定: S0={S0}, E={E}, r={r}, u={u}, d={d}, N={N}\n")
    
    final_price = american_put_binomial(S0, E, r, u, d, N)
    
    print(f"\n>>> 最终计算结果: 该美式看跌期权的当前价值为 {final_price:.4f} <<<")
```

**3. 结果分析：**
运行上述代码，程序会输出每个节点的期权价值。
- 在 $t=0$ 到 $t=N-1$ 的过程中，如果标的股票价格大幅下跌（例如连续下跌导致 $S < E$），此时内在价值 $\max(E - S, 0)$ 可能会大于继续持有的期望折现价值。
- 此时，程序中的 `max(hold_value, exercise_value)` 就会选择 `exercise_value`，这在数学上精确模拟了美式期权“提前行权”的特性。
- 对比同等参数的欧式看跌期权，美式看跌期权的价格通常会更高，因为提前行权的灵活性增加了期权的价值。
