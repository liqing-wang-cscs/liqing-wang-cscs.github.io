# 一、均值方差模型的理论知识

## 问题A1：什么是马科维茨的均值方差模型？

**提问：** 
现代投资组合理论（MPT）的基石——马科维茨均值-方差模型（Markowitz Mean-Variance Model）是由谁在何时提出的？该模型如何量化投资的“收益”与“风险”？其最核心的投资机制是什么，又是如何指导理性投资者进行决策的？

<details>
<summary>解答：</summary>

### 1. 理解问题
对于初学者来说，均值-方差模型的核心可以概括为四个字：“分散投资”。在模型提出之前，人们往往只盯着单个股票“能赚多少钱”（收益）或“风险有多大”。而马科维茨首次用数学证明了：**投资组合的整体风险，不仅仅取决于单只股票的风险，更取决于这些股票之间的“联动性”（相关性）**。只要买的是走势不完全一致的股票，就能在不降低预期收益的情况下，把整体风险降下来。

### 2. 解答问题
该模型由哈里·马科维茨（Harry Markowitz）于1952年提出，首次将数理统计方法引入金融投资领域。其核心思想是：投资决策不应只关注单个资产的收益，而应关注整个投资组合的风险与收益平衡。

*   **均值（预期收益率）**：衡量投资的预期回报，是组合内各资产预期收益的加权平均。
*   **方差（风险）**：衡量投资收益的波动程度（即风险）。方差越大，风险越高。
*   **核心机制**：投资组合的整体风险不仅取决于单个资产的风险，更取决于资产之间的相关性（协方差）。通过投资于低相关性的资产，可以在不牺牲预期收益的前提下，相互抵消波动，从而降低非系统性风险。
*   **有效边界**：模型通过数学推导，在风险-收益坐标系中画出了一条“有效边界”。理性的投资者应当在这条边界上，选择与自身风险偏好相匹配的最优投资组合。

</details>

## 问题A2：什么是最小方差投资组合？

**提问：** 
在均值-方差模型构建的所有可行投资组合中，什么是“最小方差投资组合”（Minimum-Variance Portfolio）？它在风险-收益的有效边界曲线上处于什么特殊位置？对于极度厌恶风险的投资者而言，它具有怎样的现实意义？

<details>
<summary>解答：</summary>

### 1. 理解问题
你可以把“最小方差投资组合”想象成投资组合世界里的“避风港”。在所有的股票组合中，有的组合收益高但波动大，有的组合收益低但很平稳。最小方差组合就是那个**波动率最小**的组合。如果你是一个极度保守的投资者，看到账户亏损就睡不着觉，那么这个组合就是你的最优解。在图表上，它就是那条“有效边界”曲线最靠左、最突出的那个顶点。

### 2. 解答问题
最小方差投资组合是指在所有可能的投资组合中，整体风险（方差）达到绝对最低的那个特定组合。

*   **位置**：在均值-方差模型的有效边界曲线上，它通常位于最左侧的顶点（即全局最小方差组合，GMVP）。
*   **意义**：它是风险厌恶型投资者的“避风港”。如果你只追求极致的平稳，不希望看到账户出现大幅波动，这就是你的最佳选择。
*   **计算方法**：在数学上，它是一个带约束条件的优化问题。目标是最小化投资组合的方差（基于各资产的方差和协方差矩阵），约束条件是所有资产的投资权重之和等于1。

</details>

## 问题A3：什么是两基金分离定理？

**提问：** 
被誉为资产组合理论核心结论的“两基金分离定理”（Two-Fund Separation Theorem），是如何将复杂的投资决策进行拆解的？该定理揭示了投资者的“个人风险偏好”与“最优风险资产组合的构成”之间存在怎样的关系？它对现代金融基金产品的设计有何深远影响？

<details>
<summary>解答：</summary>

### 1. 理解问题
这个定理听起来很高深，但它的核心逻辑非常接地气：**“众口难调，但好资产是一样的”**。定理告诉我们，不管你是保守的老爷爷，还是激进的年轻人，你们在买“风险资产”（比如股票）时，买的那一篮子股票的**内部比例是完全一样的**！你们的区别仅仅在于：老爷爷可能把 90% 的钱存银行，10% 买这篮子股票；而年轻人可能把 10% 存银行，90% 买这篮子股票。这就把“选什么股票”和“能承受多大风险”这两件事彻底分开了。

### 2. 解答问题
又称共同基金分离定理，是资产组合理论的核心结论之一，由詹姆斯·托宾等人进一步阐述和推广。

*   **核心含义**：投资者的最优风险资产组合，与其个人的风险偏好是**完全独立**的。
*   **决策分离**：该定理将投资决策分为两个独立的阶段：
    1.  **资产选择决策**：确定最优的风险资产组合（即市场组合或切点组合）。这个组合的构成对所有人都是一样的。
    2.  **资本配置决策**：根据个人的风险厌恶程度，决定将多少资金投入到上述最优风险组合中，多少资金投入到无风险资产（如国债）中。
*   **现实意义**：这意味着，无论是保守型还是激进型投资者，他们持有的“风险资产部分”的内部结构是完全相同的，区别仅仅在于投入风险资产的总资金比例不同。这为现代共同基金、FOF等基金产品的设计提供了直接的理论依据。

</details>

## 步骤一：数据获取与准备

### 问题 B1：如何批量获取并整理多只股票的历史行情数据？

在构建投资组合之前，我们需要获取真实的市场数据。请描述如何使用 Tushare Pro 接口，批量下载指定股票池（如宁德时代、中芯国际等）近三个月的收盘价数据，并将其保存为本地 CSV 文件以供后续使用？

<details>
<summary>解答与代码实现：</summary>

**核心思路：**
1.  **初始化接口**：连接 Tushare 服务器。
2.  **循环请求**：遍历股票代码列表，逐个获取日线行情。
3.  **数据拼接**：将单只股票的数据合并成一个总表。
4.  **清洗存储**：排序并保存为 CSV，注意处理中文编码问题。

```python
import tushare as ts
import pandas as pd

# 1. 初始化接口（请替换为你自己的真实 Token）
ts.set_token('你的Tushare_Token')
pro = ts.pro_api()

# 2. 定义股票代码列表和时间范围
# 注意：A股代码需带后缀（.SH 或 .SZ），日期格式为 YYYYMMDD
stock_codes = [
    '688041.SH', # 海光信息
    '688981.SH', # 中芯国际
    '688256.SH', # 寒武纪
    '688012.SH', # 中微公司
    '603986.SH', # 兆易创新
    '600276.SH', # 恒瑞医药
    '688008.SH'  # 澜起科技
]
start_date = '20260526'
end_date = '20260826'

# 3. 初始化一个空的 DataFrame 用于存放合并后的数据
df_all = pd.DataFrame()

# 4. 循环获取每只股票的收盘价数据
for code in stock_codes:
    print(f"正在获取 {code} 的数据...")
    # 调用 daily 接口，仅提取代码、日期和收盘价，提高效率
    df = pro.daily(
        ts_code=code, 
        start_date=start_date, 
        end_date=end_date, 
        fields='ts_code,trade_date,close' 
    )
    # 将单只股票的数据纵向拼接到总表中
    df_all = pd.concat([df_all, df], ignore_index=True)

# 5. 数据清洗：按股票代码和交易日期进行升序排序，方便后续查看
df_all = df_all.sort_values(['ts_code', 'trade_date'])

# 6. 保存数据
# 使用 utf-8-sig 编码，防止在 Excel 中打开中文出现乱码
df_all.to_csv('tech_stocks_4.csv', index=False, encoding='utf-8-sig')
print("\n数据已成功保存为 tech_stocks_4.csv！")
```

</details>

## 步骤三：核心指标计算

### 问题 B3：如何计算对数收益率与协方差矩阵？

在均值-方差模型中，我们关注的是“收益率”而非“价格”，以及资产间的“联动性”。请解释如何从收盘价计算对数收益率，并构建协方差矩阵，最后将其序列化保存以便后续优化步骤调用？

<details>
<summary>解答与代码实现：</summary>

**核心思路：**
1.  **对数收益率**：使用 `np.log(P_t / P_{t-1})` 计算，具有时间可加性。
2.  **协方差矩阵**：使用 Pandas 的 `.cov()` 方法计算，衡量资产间的联动风险。
3.  **序列化保存**：使用 `pickle` 将复杂的矩阵对象保存为二进制文件。

```python
import pandas as pd
import numpy as np
import pickle

# 1. 载入本地 CSV 数据
# parse_dates 参数直接在读取时将日期列解析为时间对象
df = pd.read_csv('tech_stocks_7.csv', sep=',', encoding='gbk', parse_dates=['日期'])

# 2. 数据预处理：将“日期”设置为索引
df.set_index('日期', inplace=True)

# 3. 计算每日对数收益率
# 公式：ln(P_t / P_{t-1})
# shift(1) 将数据向下移动一行以获取昨日价格
log_returns = np.log(df / df.shift(1)).dropna()

print("--- 每日对数收益率 (前5行) ---")
print(log_returns.head())

# 4. 计算协方差矩阵
# cov() 方法自动计算各列之间的协方差，这是衡量风险联动的核心
cov_matrix = log_returns.cov()

print("\n--- 收益率协方差矩阵 ---")
print(cov_matrix)

# 5. 保存数据
# 将计算好的收益率和协方差矩阵打包保存，供下一步优化使用
data_to_save = {
    'log_returns': log_returns,
    'cov_matrix': cov_matrix
}
# 以二进制写入模式 ('wb') 保存
with open('portfolio_data_7.pkl', 'wb') as f:
    pickle.dump(data_to_save, f)
print("变量已成功保存！")
```

## 步骤四：投资组合优化求解

### 问题 B4：如何利用优化算法求解最小方差投资组合？

已知资产的协方差矩阵，如何通过数学规划求解出风险（方差）最小的资产权重分配？请描述如何使用 `scipy.optimize` 库，在满足“权重和为1”且“不可卖空”的约束条件下，寻找最优解？

<details>
<summary>解答与代码实现：</summary>

**核心思路：**
1.  **定义目标函数**：计算组合方差 $W^T \Sigma W$。
2.  **设定约束**：权重之和等于1（全额投资），权重范围在 0-1 之间（不可卖空）。
3.  **求解**：使用 SLSQP 算法进行最小化求解。

```python
import pickle
from scipy.optimize import minimize
import numpy as np

# 1. 加载数据
with open('portfolio_data_7.pkl', 'rb') as f:
    loaded_data = pickle.load(f)
log_returns = loaded_data['log_returns']
cov_matrix = loaded_data['cov_matrix']

# 2. 定义目标函数：计算投资组合的方差
# 数学公式：Variance = W' * Cov * W
def portfolio_variance(weights, cov_matrix):
    return np.dot(weights.T, np.dot(cov_matrix, weights))

# 3. 设定约束条件
# 约束1：所有权重之和必须等于 1 (sum(w) = 1)
constraints = ({'type': 'eq', 'fun': lambda x: np.sum(x) - 1})

# 约束2：权重边界
# A股通常不允许卖空，且为了防止权重过于集中或为0，设定每只股票至少 1%
bounds = tuple((0.01, 1.0) for _ in range(len(log_returns.columns)))

# 4. 设定初始权重猜测（平均分配）
init_weights = np.array([1.0 / len(log_returns.columns)] * len(log_returns.columns))

# 5. 运行优化算法
# method='SLSQP' 是处理带约束非线性优化的经典算法
result = minimize(
    portfolio_variance, 
    init_weights, 
    args=(cov_matrix,), 
    method='SLSQP', 
    bounds=bounds, 
    constraints=constraints
)

# 6. 输出结果
print("\n--- 最小方差投资组合结果 ---")
print("最优权重分配:")
for asset, weight in zip(log_returns.columns, result.x):
    print(f"{asset}: {weight:.2%}")

# 计算并输出组合的最小波动率（年化）
min_variance = result.fun
annual_volatility = np.sqrt(min_variance * 252) # 252为年交易日数
print(f"\n组合最小方差: {min_variance:.6f}")
print(f"组合年化波动率: {annual_volatility:.2%}")
```

</details>

## 步骤五：有效边界可视化

### 问题 B5：如何通过蒙特卡洛模拟绘制有效边界并标记最优组合？

为了直观展示风险与收益的权衡关系，如何使用蒙特卡洛模拟随机生成大量投资组合，绘制出“风险-收益”散点图（有效边界），并在图中标记出“最小方差组合”和“最大夏普比率组合”？

<details>
<summary>解答与代码实现：</summary>

**核心思路：**
1.  **蒙特卡洛模拟**：随机生成 1000 组权重，计算每组的预期收益和风险。
2.  **寻找极值**：找出夏普比率最高（性价比最高）和风险最低（最左侧）的点。
3.  **绘图**：绘制散点图，用颜色区分夏普比率，并标记关键点。

```python
import pickle
import numpy as np
import matplotlib.pyplot as plt

# --- 配置中文字体 ---
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 1. 加载数据
with open('portfolio_data_7.pkl', 'rb') as f:
    loaded_data = pickle.load(f)
log_returns = loaded_data['log_returns']
cov_matrix = loaded_data['cov_matrix']

# 2. 蒙特卡洛模拟：随机生成 1000 个投资组合
num_portfolios = 1000
# 创建数组存储结果：[收益, 风险, 夏普比率]
results = np.zeros((3, num_portfolios))

for i in range(num_portfolios):
    # 随机生成权重并归一化（确保总和为 1）
    weights = np.random.random(len(log_returns.columns))
    weights /= np.sum(weights)
    
    # 计算年化预期收益 (均值 * 252)
    portfolio_return = np.sum(log_returns.mean() * weights) * 252
    
    # 计算年化波动率 (sqrt(W' * Cov * W * 252))
    portfolio_std = np.sqrt(np.dot(weights.T, np.dot(cov_matrix * 252, weights)))
    
    # 计算夏普比率 (假设无风险利率为 1%)
    sharpe_ratio = (portfolio_return - 0.010) / portfolio_std
    
    # 保存结果
    results[0, i] = portfolio_return
    results[1, i] = portfolio_std
    results[2, i] = sharpe_ratio

# 3. 寻找关键的最优投资组合
# 最大夏普比率组合（性价比最高）
max_sharpe_idx = np.argmax(results[2])
max_sharpe_ret, max_sharpe_std = results[0, max_sharpe_idx], results[1, max_sharpe_idx]

# 最小方差组合（风险最低）
min_vol_idx = np.argmin(results[1])
min_vol_ret, min_vol_std = results[0, min_vol_idx], results[1, min_vol_idx]

# 4. 绘制有效边界图
plt.figure(figsize=(10, 7))

# 绘制所有随机组合的散点，颜色映射为夏普比率
scatter = plt.scatter(results[1, :], results[0, :], c=results[2, :], cmap='viridis', marker='o', s=15, alpha=0.4)

# 标记最大夏普比率组合 (红色星号)
plt.scatter(max_sharpe_std, max_sharpe_ret, marker='*', color='red', s=300, label='最大夏普比率')

# 标记最小方差组合 (绿色星号)
plt.scatter(min_vol_std, min_vol_ret, marker='*', color='green', s=300, label='最小方差')

# 添加图表信息
plt.title('A股科技股有效边界 (Efficient Frontier)', fontsize=16)
plt.xlabel('年化波动率 / 风险', fontsize=12)
plt.ylabel('年化预期收益', fontsize=12)
plt.colorbar(label='夏普比率') # 显示颜色条
plt.legend(fontsize=12, loc='best')
plt.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()

# 显示图表
```
