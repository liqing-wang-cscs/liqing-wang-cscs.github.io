# 课程论文作业：《数学人才需求调研报告》

课程名称：人工智能导论（数学版）/ 数学编程与职业启航  
适用对象：2026级数学与应用数学1-2班  
布置周次：第10周（11.9）  
提交截止：第15周（12.14）  

## 一、作业目的

本课程论文不是传统的“学术论文”，而是一份有数据、有判断、有自我定位的职业调研报告。你需要在调研的基础上回答一个核心问题：

> “作为一名数学与应用数学专业的大一学生，我在“数学+AI”相关的领域里，未来四年应该往哪个方向准备？”

报告由五个板块构成：学科竞赛、AI 大厂与术语、AI 开发社区、文献资源、招聘需求。五个板块环环相扣——竞赛告诉你“用什么证明自己”，大厂和社区告诉你“行业在发生什么”，文献告诉你“学术前沿在哪里”，招聘需求告诉你“市场要什么”，最后落到你自己的规划上。这份报告的价值在于你通过调研，对自己未来四年的路有了比开学时更清楚一点的认识。

## 二、调研任务（你需要做的事情）

请围绕以下五个板块展开调研，并将调研结果整理成报告。每个板块都附有需要你在报告中明确回答的具体问题，请逐一作答。


### 板块一：数学、数学建模、应用统计的学科竞赛调研

调研对象：以下三类竞赛中，每一类至少了解一个，总共至少了解四个竞赛。

（1）数学类学科竞赛
- 全国大学生数学竞赛（中国数学会主办）：分数学专业组与非数学专业组，数学专业组考察数学分析、高等代数、解析几何，初赛通常在11月。是数学专业最对口的学科竞赛，获奖在考研复试中认可度高。
- 丘成桐大学生数学竞赛（丘成桐先生发起）：面向高年级本科生，难度高、含金量高，适合学有余力者关注。

（2）数学建模类竞赛
- 全国大学生数学建模竞赛（国赛）（中国工业与应用数学学会主办）：国内规模最大、认可度最高的数模竞赛，通常9月中旬举行，3天开卷实战。
- 美国大学生数学建模竞赛（美赛）：需提交英文论文，通常1月底至2月初举行，有报名费。
- 五一数学建模竞赛、长三角高校数学建模竞赛、MathorCup 数学应用挑战赛：多安排在国赛之前（4—5月），适合作为热身、磨合队友、积累经验的练手赛事。

（3）应用统计类竞赛
- 全国大学生统计建模大赛（中国统计教育学会主办）：统计学科最高级别的专业竞赛，入选《全国普通高校大学生竞赛分析报告》竞赛目录。3人组队，围绕年度主题撰写统计建模论文，通常3月启动、5月提交论文、6月省赛、7—8月国赛。国奖获奖率不到5%，含金量高、难度较大。
- 全国大学生市场调查与分析大赛（市调大赛）（中国商业统计学会主办）：长期位居全国一级A类竞赛行列，分知识赛（个人在线理论考试）和实践赛（团队调研报告+答辩）两阶段，团队3—5人。侧重调研设计与统计分析的实际应用，难度中等。

需要回答的问题：

1. 从上述三类竞赛中，各选一个你最感兴趣的，填写下表（请通过搜索确认信息，不要照抄示例）：

| 竞赛名称 | 类别（数学/建模/统计） | 主办方 | 大致时间 | 含金量/特点（一句话） | 你感兴趣的原因（一句话） |
|---|---|---|---|---|---|
| （示例）全国大学生数学竞赛 | 数学 | 中国数学会 | 11月初赛 | 数学专业最对口，考研复试认可度高 | 考的就是我正在学的课程 |
| | | | | | |
| | | | | | |
| | | | | | |

2. 国赛与美赛的核心区别是什么？请从语言要求、题目风格、获奖难度与含金量、参赛费用中至少选两个角度对比。
3. 统计建模大赛与市调大赛的区别是什么？请从竞赛形式（论文 vs. 调研报告+答辩）、组队要求、与你目前数学课程的关联度中至少选两个角度对比。
4. 五一、长三角、MathorCup 这类竞赛，与国赛、美赛相比，在你看来更适合用来做什么？（提示：练手？磨合队友？积累经验？）请结合它们大多安排在国赛之前这一时间特点给出判断。
5. 你目前最想参加哪一个竞赛？请结合你目前的数学基础（数学分析、高等代数学到哪里了）和编程水平（Python 学到什么程度）如实说明。如果暂时觉得“都还参加不了”，也请诚实写出，并说明你打算先准备哪一个作为起步。


### 板块二：AI 模型大厂与行业术语调研

调研对象：访问不少于十家AI 相关企业的官方网站或产品页（建议包括：DeepSeek、阿里通义/千问、月之暗面/Kimi、智谱、MiniMax、腾讯混元、百度文心、字节豆包、OpenAI、Anthropic、Google DeepMind、Meta、SpaceXAI 等，可自行补充）。

需要回答的问题：

6. 从你浏览的十家企业中，挑选三家，分别用一句话概括它们当前主推的 AI 产品/模型是什么。
7. 你在浏览过程中至少遇到了五个看不懂的术语或缩写（例如：MoE、RLHF、上下文窗口、Token、推理成本、开源权重、多模态等）。请列出这五个术语，并用自己的话（可以借助 AI 工具查询后消化）各写一句解释，说明它大致是什么意思。
8. 结合你看到的信息，你认为“数学出身的人”在这些 AI 公司里最可能从事什么类型的工作？（算法研究？数据工程？模型评估？还是其他？）请给出你的判断依据。


### 板块三：AI 开发社区与代码托管平台调研

调研对象：AI 模型社区（Hugging Face、ModelScope 魔搭、AtomGit）与代码托管平台（GitHub、Gitee）。五个平台中至少了解四个。

需要回答的问题：

9. AI 模型社区对比：Hugging Face 与 ModelScope 的核心区别是什么？请从模型来源、中文支持、访问速度、生态定位中至少选两个角度比较。AtomGit 与这两者又有什么不同？（提示：AtomGit 的定位是“开源+AI”一体化，把代码、模型、算力放在同一个平台里。）

10. 代码托管平台对比：GitHub 和 Gitee 的核心区别是什么？请从访问稳定性、开源生态规模、私有仓库免费政策、社区语言环境等角度至少选两个进行比较。

11. 实操记录：在 ModelScope 或 Hugging Face 上搜索一个你感兴趣的模型（例如某个开源语言模型、图像生成模型、数学推理模型），记录：模型名称、参数量（如果标注了）、主要用途。截屏或记录关键信息附在报告附录中。如果你同时能在两个平台上找到同一个模型，顺便对比一下两边的下载体验（速度、是否需登录等）。


### 板块四：文献与数据实践资源调研

调研对象：以下两类资源中至少各了解一个：

- 学术文献类：arXiv math / cs.LG、MathSciNet、zbMATH、DBLP、Google Scholar
- 数据实践类：Kaggle、天池、和鲸社区

需要回答的问题：

12. 学术资源对比：从 MathSciNet 与 zbMATH 中选两个进行对比，或从 arXiv 与 Google Scholar 中选两个进行对比。说明它们各自主要收录什么类型的文献，以及对本科生来说哪个更容易上手使用。（提示：MathSciNet 需订阅，zbMATH 自2021年起开放获取；arXiv 是预印本平台，Google Scholar 覆盖面更广但质量参差。）

13. 数据实践平台体验：在 Kaggle、天池、和鲸社区中至少浏览两个，回答：它们各自的项目/数据集难度和定位有什么区别？（提示：Kaggle 项目完整但需英语和 Python/R 基础，天池竞赛含金量高但对新手较难，和鲸社区项目简单、流程完备，适合入门。）结合你目前的 Python 水平，你现阶段最适合从哪个平台开始练手？


### 板块五：数学人才招聘需求调研

调研对象：地图找单位、在至少两个企业官网的招聘页上，搜索以下关键词中的至少两个：“算法工程师”“数据分析师”“AI 研究员”“机器学习工程师”“数学”“数学建模”。

需要回答的问题：

14. 找到三个你觉得自己未来可能感兴趣的岗位，列出：岗位名称、公司/行业、任职要求中提到的数学或技能要求。
15. 对比这三个岗位的要求，回答：招聘方最看重的三项能力是什么？
16. （自我定位题，最重要）基于以上所有调研，写一段职业规划。必须包含以下内容：
    - 你目前最感兴趣的方向是什么？（哪怕不确定，也要选一个“暂定方向”）
    - 对照竞赛要求（板块一）和招聘要求（板块五），你已经具备什么？
    - 未来两年内，你计划具体做哪两件事来缩小差距？


## 三、报告格式要求

1. 格式：参考模板 `学号-姓名-课程论文.md`, 使用 Markdown 编写，提交 `.md` 和`.pdf` 两个文件。标题层级清晰，适当使用列表和表格（表格用于对比竞赛或岗位等）。
2. 引用：凡引用网站内容、竞赛信息或招聘信息，必须附上链接或截屏。可以在文末以“参考来源”列表呈现。
