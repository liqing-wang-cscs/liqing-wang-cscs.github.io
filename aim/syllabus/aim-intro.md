# 数学编程基础、人工智能基本知识、数学相关职业启航

本课程涵盖 LaTeX 数学排版、VS Code 开发环境、Python 编程、Markdown 写作，以及 CS336 作业实战与数学相关职业方向探索，帮助你从零搭建"数学 + 编程 + AI"的完整知识体系。

## 课程模块

| 模块 | 内容 |
|------|------|
| 📐 LaTeX 排版 | 数学公式与论文排版 |
| 🛠️ VS Code 使用 | 高效代码编辑器配置 |
| 🐍 Python 编程 | 从语法到数据分析 |
| ✏️ Markdown 编程 | 轻量级文档写作 |
| 🤖 CS336 实战 | Transformer 与 LLM |
| 🧭 职业启航 | 数学相关方向探索 |

## 使用说明

- 点击**左侧目录**中的章节名称可展开/折叠子节
- 点击**子节名称**即可在中间区域加载对应内容
- 右侧栏会自动显示当前章节的目录结构
- 点击右上角"📑 目录"按钮可切换右侧栏的显示/隐藏
