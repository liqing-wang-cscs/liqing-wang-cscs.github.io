## 关键概念
### 5.1 判别函数
- [[二分类线性判别|二分类线性判别]]：$y(x) = w^T x + w_0$，$y(x)≥0$分配给$C_1$，否则$C_2$
  - [[决策边界|决策边界]]：$w^T x + w_0 = 0$（超平面）
  - [[几何意义|几何意义]]：w是决策边界法向量，$w_0$控制边界位置
- [[多分类线性判别|多分类线性判别]]：$y_k(x) = w_k^T x + w_{k0}$，分配给$y_k(x)$最大的类
  - [[决策边界#多分类|决策边界]]：$y_k(x) = y_j(x)$（超平面）

### 5.2 概率分类模型
#### 5.2.1 生成模型
- [[生成模型#思路|思路]]：建模类条件密度$p(x|C_k)$和先验$p(C_k)$，通过贝叶斯定理求后验$p(C_k|x)$
- [[高斯生成模型|高斯生成模型]]：假设$p(x|C_k) = \mathcal{N}(x|\mu_k,\sum)$（共享协方差）
  - [[后验概率#高斯|后验概率]]：$p(C_1|x) = \sigma(w^T x + w_0)$，σ为sigmoid函数

#### 5.2.2 判别模型
- [[判别模型#思路|思路]]：直接建模后验概率$p(C_k|x)$，无需类条件密度
- [[逻辑回归|逻辑回归（二分类）]]：$p(C_1|\phi) = \sigma(w^T\phi)$，$\sigma(a) = \frac{1}{1+exp(-a)}$
  - [[交叉熵误差|交叉熵误差]]：$E(w) = -\sum_{n=1}^N [t_n ln y_n + (1-t_n)ln(1-y_n)]$
- [[多分类逻辑回归|多分类逻辑回归]]：$p(C_k|\phi) = \frac{exp(a_k)}{\sum_j exp(a_j)}$，$a_k = w_k^T\phi$（softmax）
  - [[交叉熵误差#多分类|交叉熵误差]]：$E(w_1,...,w_K) = -\sum_{n=1}^N \sum_{k=1}^K t_{nk} ln y_{nk}$

### 5.3 决策理论与评估
- [[损失矩阵|损失矩阵]]：量化不同分类错误的损失（如漏诊损失>误诊损失）
- [[分类指标|分类指标]]
  - [[混淆矩阵|混淆矩阵]]：展示真阳性(TP)、假阳性(FP)、真阴性(TN)、假阴性(FN)
  - [[精确率|精确率]]：$\frac{TP}{TP+FP}$，[[召回率|召回率]]：$\frac{TP}{TP+FN}$
  - [[F1分数|F1分数]]：$\frac{2×精确率×召回率}{精确率+召回率}$
- [[ROC曲线|ROC曲线]]：以假阳性率为横轴，真阳性率为纵轴，AUC衡量整体性能

### 5.4 其他分类相关
- [[拒绝选项|拒绝选项]]：对后验概率低于阈值θ的样本拒绝分类
- [[朴素贝叶斯|朴素贝叶斯]]：假设特征条件独立，$p(x|C_k) = \prod_{i=1}^D p(x_i|C_k)$
- [[概率单位回归|概率单位回归]]：激活函数为probit函数（高斯累积分布）

## 概念关系
- [[逻辑回归]] → [[单层神经网络]]：输出层为sigmoid激活的单层网络
- [[生成模型 vs 判别模型|生成模型 vs 判别模型]]：生成模型建模联合概率，判别模型直接建模后验
- [[softmax]] → [[sigmoid]]：K=2时softmax退化为sigmoid
- [[ROC曲线]] → [[分类阈值]]：曲线由不同分类阈值下的TPR/FPR绘制而成
