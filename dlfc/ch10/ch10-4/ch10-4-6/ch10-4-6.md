### 10.4.6 Fast region CNNs

### P13

Another way to speed up object detection and localization is to note that a scanning window approach applies the full power of a deep convolutional network to all areas of the image, even though some areas may be unlikely to contain an object. Instead, we can apply some form of computationally cheaper technique, for example a segmentation algorithm, to identify parts of the image where there is a higher probability of finding an object, and then apply the full network only to these areas, leading to techniques such as *fast region proposals with CNN* or *fast R-CNN* (Girshick, 2015). It is also possible to use a *region proposal* convolutional network to identify the most promising regions, leading to *faster R-CNN* (Ren *et al*., 2015), which allows end-to-end training of both the region proposal network and the detection and localization network.

### P14

A disadvantage of the sliding window approach is that if we want a very precise localization the objects then we need to consider large numbers of finely spaced window positions, which becomes computationally costly. A more efficient approach is to combine sliding windows with the direct bounding box predictions that we discussed at the start of this section (Sermanet *et al*., 2013). In this case, the continuous outputs predict the position of the bounding box relative to the window position and therefore provide some fine-tuning to the predicted position.

### 10.4.6 快速区域 CNN

### P13

加快目标检测和定位的另一种方法是注意到，扫描窗口方法会将深度卷积网络的完整能力应用于图像的所有区域，即使某些区域不太可能包含物体。相反，我们可以应用某种计算成本更低的技术，例如分割算法，来识别图像中更可能找到物体的部分，然后仅对这些区域应用完整网络，从而产生诸如*基于 CNN 的快速区域提议*或*快速 R-CNN*（Girshick, 2015）之类的技术。也可以使用*区域提议*卷积网络来识别最有希望的区域，从而产生*更快的 R-CNN*（Ren *et al*., 2015），它允许对区域提议网络以及检测和定位网络进行端到端训练。

### P14

滑动窗口方法的一个缺点是，如果我们想要非常精确地定位物体，那么需要考虑大量密集间隔的窗口位置，这在计算上变得昂贵。一种更高效的方法是将滑动窗口与我们在本节开头讨论的直接边界框预测结合起来（Sermanet *et al*., 2013）。在这种情况下，连续输出预测边界框相对于窗口位置的位置，因此为预测位置提供了一些微调。

## 重点总结

1. **滑动窗口的计算浪费**  
   滑动窗口方法将完整深度卷积网络应用于图像所有区域，即使某些区域不太可能包含物体，造成计算浪费。

2. **快速 R-CNN 的思想**  
   先使用计算成本较低的技术（如分割算法）识别可能包含物体的区域，然后仅对这些区域应用完整网络，从而提高效率。

3. **更快的 R-CNN**  
   使用区域提议卷积网络来识别最有希望的区域，允许区域提议网络与检测定位网络进行端到端训练。

4. **滑动窗口与直接边界框预测结合**  
   为获得精确局部化，可将滑动窗口与直接边界框预测结合：连续输出预测边界框相对于窗口位置的位置，从而对预测位置进行微调。

5. **效率与精度的权衡**  
   滑动窗口若追求高精度需大量密集窗口位置，计算成本高；结合直接边界框预测可在保持精度的同时提高效率。

## 难点总结

1. **理解快速 R-CNN 与更快的 R-CNN 的区别**  
   快速 R-CNN 使用外部低成本方法生成区域提议；更快的 R-CNN 使用区域提议网络，实现端到端训练。

2. **区域提议的作用**  
   需要理解区域提议如何筛选出可能包含物体的区域，从而避免对整张图像应用完整网络。

3. **端到端训练的含义**  
   更快的 R-CNN 允许区域提议网络和检测定位网络一起训练，需要理解这与分阶段训练的区别。

4. **滑动窗口与直接边界框预测的结合方式**  
   需要理解连续输出如何预测边界框相对于窗口位置的偏移，以及这种微调如何提高定位精度。

5. **精度与计算成本的平衡**  
   需要理解为什么密集窗口位置能提高精度但增加成本，以及结合直接边界框预测如何缓解这一问题。
