# CONVOLUTIONAL NETWORKS 卷积网络

### P1 第1段：非结构化数据的假设

The simplest machine learning models assume that the observed data values are unstructured, meaning that the elements of the data vectors $\mathbf{x} = (x_1, \dots, x_D)$ are treated as if we do not know anything in advance about how the individual elements might relate to each other. 

If we were to make a random permutation of the ordering of these variables and apply this fixed permutation consistently on all training and test data, there would be no difference in the performance for the models considered so far.

最简单的机器学习模型假设观测数据值是非结构化的，即数据向量 $\mathbf{x} = (x_1, \dots, x_D)$ 中的各个元素被视为我们事先不知道它们之间可能存在的任何关联关系。

如果我们对这些变量的顺序进行随机置换，并在所有训练和测试数据上一致地应用这个固定置换，那么对于目前所考虑的模型来说，其性能不会有任何差异。

**重点难点**  

- 本段点明了传统模型对数据“无序性”的隐含假设，这是理解后续结构化数据建模需求的起点。  

- 关键概念是“随机置换不影响性能”，这反过来说明模型没有利用任何位置或顺序信息，是后续对比的基线。

---

### P2 第2段：结构化数据与局部相关性

Many applications of machine learning, however, involve **structured data** in which there are additional relationships between input variables. 

For example, the words in natural language form a **sequence**, and if we were to model language as a generative autoregressive process then we would expect each word to depend more strongly on the immediately preceding words and less so on words much earlier in the sequence. 

Likewise, the pixels of an image have a well-defined spatial relationship to each other in which the input variables are arranged in a two-dimensional grid, and nearby pixels have highly correlated values.

然而，机器学习的许多应用涉及**结构化数据**，其中输入变量之间存在额外的关联关系。

例如，自然语言中的单词构成**序列**，如果我们将语言建模为自回归生成过程，那么我们会预期每个单词更强地依赖于紧邻的前几个单词，而对序列中更早的单词依赖较弱。

同样，图像的像素之间具有明确的空间位置关系，输入变量排列成二维网格，并且邻近像素的值具有高度相关性。

**重点难点**  

- 引入“结构化数据”概念，并举例说明序列（文本）和空间网格（图像）中的局部依赖性。  

- 核心难点是理解“局部相关性”作为先验知识，这是后续卷积网络设计的基础动机。

---

### P3 第3段：利用结构先验的正则化与架构设计

We have already seen that our knowledge of the structure of specific data modalities can be utilized through the addition of a regularization term to the error function in the training objective, through data augmentation, or through modifications to the model architecture. 

These approaches can help guide the model to respect certain properties such as invariance and equivariance with respect to transformations of the input data. 

In this chapter we will take a look at an architectural approach called a **convolutional neural network** (CNN), which we will see can be viewed as a sparsely connected multilayer network with parameter sharing, and designed to encode invariances and equivariances specific to image data.

我们已经看到，我们对特定数据模态结构的了解，可以通过在训练目标中向误差函数添加正则化项、通过数据增强，或通过修改模型架构来加以利用。

这些方法有助于引导模型尊重某些性质，例如对输入数据变换的不变性和等变性。

在本章中，我们将研究一种称为**卷积神经网络**（CNN）的架构方法，我们将看到它可以被视为具有参数共享的稀疏连接多层网络，并且被设计用于编码图像数据特有的不变性和等变性。

**重点难点**  

- 总结了利用结构知识的几种途径（正则化、数据增强、架构设计），并引出CNN。 

- 关键难点是理解“稀疏连接”和“参数共享”如何实现，以及“不变性”与“等变性”的区别（不变性指输出不随变换改变，等变性指输出随输入变换而相应变换）。

## Computer Vision 计算机视觉

### P4 第4段：计算机视觉与CNN的历史地位

The automatic analysis and interpretation of image data form the focus of the field of computer vision and represent a major application area for machine learning (Szeliski, 2022). 

Historically, computer vision was based largely on 3-dimensional projective geometry. 

Hand-crafted features were constructed and used as input to simple learning algorithms (Hartley and Zisserman, 2004). 

However, it was one of the first fields to be transformed by the deep learning revolution, predominantly thanks to the CNN architecture. 

Although the architecture was originally developed in the context of image analysis, it has also been applied in other domains such as the analysis of sequential data. 

Recently alternative architectures based on transformers have become competitive with convolutional networks in some applications.

图像数据的自动分析和解释构成了计算机视觉领域的核心，也是机器学习的一个重要应用领域（Szeliski, 2022）。

历史上，计算机视觉主要基于三维射影几何。

人们构造手工设计的特征，并将其输入到简单的学习算法中（Hartley 和 Zisserman, 2004）。

然而，它是深度革命最早被彻底改变的领域之一，这主要归功于CNN架构。

尽管该架构最初是在图像分析背景下开发的，但它也被应用于其他领域，如序列数据分析。

最近，基于transformer的替代架构在某些应用中已能与卷积网络相抗衡。

**重点难点**  

- 概述计算机视觉的历史演变，强调CNN带来的范式转变。  

- 难点在于理解CNN为何特别适合图像（局部性、平移等变性），同时注意transformers作为竞争者的现状。

### P5 第5段：计算机视觉常见应用任务

There are many applications for machine learning in computer vision, of which some of the most commonly encountered are the following:

1. **Classification** of images, for example classifying an image of a skin lesion as benign or malignant. 

This is sometimes called `image recognition'.

2. **Detection** of objects in an image and determining their locations within the image, for example detecting pedestrians from camera data collected by an autonomous vehicle.

3. **Segmentation** of images, in which each pixel is classified individually thereby dividing the image into regions sharing a common label. 

For example, a natural scene might be segmented into sky, grass, trees, and buildings, whereas a medical scan image could be segmented into cancerous tissue and normal tissue.

4. **Caption generation** in which a textual description is generated automatically from an image.

5. **Synthesis** of new images, for example generating images of human faces. 

Images can also be synthesized based on a text input describing the desired image content.

6. **Inpainting** in which a region of an image is replaced with synthesized pixels that are consistent with the rest of the image. 

This is used, for example, to remove unwanted objects during image editing.

7. **Style transfer** in which an input image in one style, for example a photograph, is transformed into a corresponding image in a different style, for example an oil painting.

8. **Super-resolution** in which the resolution of an image is improved by increasing the number of pixels and synthesizing associated high-frequency information.

9. **Depth prediction** in which one or more views are used to predict the distance of the scene from the camera at each pixel in a target image.

10. **Scene reconstruction** in which one or more two-dimensional images of a scene are used to reconstruct a three-dimensional representation.

机器学习在计算机视觉中有许多应用，其中最常见的有以下几种：

1. **分类**——对图像进行分类，例如将皮肤病变图像分类为良性或恶性。有时也称为“图像识别”。

2. **检测**——检测图像中的物体并确定它们在图像中的位置，例如从自动驾驶车辆采集的摄像头数据中检测行人。

3. **分割**——对每个像素单独分类，从而将图像划分为具有共同标签的区域。

例如，自然场景可能被分割为天空、草地、树木和建筑物，而医学扫描图像可被分割为癌组织和正常组织。

4. **字幕生成**——从图像自动生成文本描述。

5. **合成**——生成新图像，例如生成人脸的图像。也可以基于描述所需图像内容的文本输入来合成图像。

6. **修复**——将图像中的某个区域替换为与图像其余部分一致的合成像素。例如，在图像编辑中用于移除不需要的物体。

7. **风格迁移**——将一种风格（如照片）的输入图像转换为另一种风格（如油画）的对应图像。

8. **超分辨率**——通过增加像素数量并合成相关的高频信息来提高图像的分辨率。

9. **深度预测**——利用一个或多个视图来预测目标图像中每个像素处场景到相机的距离。

10. **场景重建**——利用场景的一个或多个二维图像来重建三维表示。

**重点难点**  

- 列举了10种典型任务，覆盖从理解到生成的广泛范围。  

- 难点在于区分分类、检测、分割的粒度差异，以及生成类任务（合成、修复、风格迁移、超分辨率）与判别类任务的不同目标。

## Image data 图像数据

### P6 第6段：图像数据的表示与维度

An image comprises a rectangular array of pixels, in which each pixel has either a grey-scale intensity or more commonly a triplet of red, green, and blue **channels** each with its own intensity value. 

These intensities are non-negative numbers that also have some maximum value corresponding to the limits of the camera or other hardware device used to capture the image. 

For the most part, we will view the intensities as continuous variables, but in practice they are represented with finite precision, for example as 8-bit numbers represented as integers in the range $0, \dots, 255$. 

Some images, such as the magnetic resonance imaging (MRI) scans used in medical diagnosis, comprise three-dimensional grids of **voxels**. 

Similarly, videos comprise a sequence of two-dimensional images and therefore can also be viewed as three-dimensional structures in which successive frames are stacked through time.

图像由像素的矩形阵列组成，其中每个像素要么具有灰度强度，或者更常见的是具有红色、绿色和蓝色**通道**的三元组，每个通道都有自己的强度值。

这些强度是非负数，并且具有某个最大值，该最大值对应于用于捕获图像的相机或其他硬件设备的限制。

在大多数情况下，我们将这些强度视为连续变量，但在实际中它们以有限精度表示，例如用范围 $0, \dots, 255$ 内的整数表示的8位数字。

某些图像，如用于医学诊断的磁共振成像（MRI）扫描，由三维体素网格组成。

类似地，视频由二维图像序列组成，因此也可以视为三维结构，其中连续帧在时间上堆叠。

**重点难点**  

- 明确图像数据的基本表示（通道、像素强度、有限精度），并扩展到三维（体素、视频）。  

- 难点在于理解不同数据维度的含义（2D图像、3D体积、视频=空间+时间），以及连续与离散表示的差异。

### P7 第7段：图像高维性与结构化先验的重要性

Now consider the challenge of applying neural networks to image data to address some of the applications highlighted above. 

Images generally have a high dimensionality, with typical cameras capturing images comprising tens of megapixels. 

Treating the image data as unstructured may therefore require a model with a vast number of parameters that would be infeasible to train. 

More significantly, such an approach fails to take account of the highly structured nature of image data, in which the relative positions of different pixels play a crucial role. 

We can see this because if we take the pixels of an image and randomly permute them, then the result no longer looks like a natural image. 

Similarly, if we generate a synthetic image by drawing random values for the pixel intensities independently for each pixel, there is essentially zero chance of generating something that looks like a natural image. 

Local correlations are important, and in a natural image there is a much higher probability that two nearby pixels will have similar colours and intensities compared to two pixels that are far apart. 

This represents powerful prior knowledge and can be used to encode strong inductive biases into a neural network, leading to models with far fewer parameters and with much better generalization accuracy.

现在考虑将神经网络应用于图像数据以解决上述一些应用所面临的挑战。

图像通常具有高维性，典型相机捕获的图像包含数千万像素。

将图像数据视为非结构化的，可能需要具有海量参数的模型，这将是不可行训练的。

更重要的是，这种方法未能考虑图像数据高度结构化的特性，其中不同像素的相对位置起着至关重要的作用。

我们可以看到这一点，因为如果我们对图像的像素进行随机排列，那么结果看起来就不再像自然图像。

类似地，如果我们通过为每个像素独立绘制随机强度值来生成合成图像，那么生成看起来像自然图像的东西的概率基本上为零。

局部相关性很重要，在自然图像中，两个邻近像素具有相似颜色和强度的概率远高于两个相距很远的像素。

这代表了强大的先验知识，可以用来向神经网络编码强烈的归纳偏置，从而产生参数少得多且泛化精度高得多的模型。

**重点难点**  

- 阐述高维性导致参数爆炸的问题，并强调结构化先验（局部相关性）是解决该问题的关键。  

- 难点在于理解“随机置换”和“独立随机生成”两个思想实验如何证明图像的结构性，以及“归纳偏置”如何通过局部连接和参数共享来提升泛化能力。
