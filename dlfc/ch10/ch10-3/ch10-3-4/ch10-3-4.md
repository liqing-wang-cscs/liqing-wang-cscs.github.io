## 10.3.4 Adversarial attacks

Gradients with respect to changes in the input image pixel values can also be used to create **adversarial attacks** against convolutional networks (Szegedy *et al.*, 2013). These attacks involve making very small modifications to an image, at a level that is imperceptible to a human, which cause the image to be misclassified by the neural network. One simple approach to creating adversarial images is called the *fast gradient sign method* (Goodfellow, Shlens, and Szegedy, 2014). This involves changing each pixel value in an image $\mathbf{x}$ by a fixed amount $\epsilon$ with a sign determined by the gradient of an error function $E(\mathbf{x}, t)$ with respect to the pixel values. This gives a modified image defined by

$$
\mathbf{x}' = \mathbf{x} + \epsilon \operatorname{sign}(\nabla_{\mathbf{x}} E(\mathbf{x}, t)). \tag{10.11}
$$

Here $t$ is the true label of $\mathbf{x}$, and the error $E(\mathbf{x}, t)$ could, for example, be the negative log likelihood of $\mathbf{x}$. The required gradient can be computed efficiently using backpropagation. During conventional training of a neural network, the network parameters are adjusted to minimize this error, whereas the modification defined by (10.11) alters the image (while keeping the trained network parameters fixed) so as to increase the error. By keeping $\epsilon$ small, we ensure that the changes to the image are undetectable to the human eye. Remarkably, this can give images that are misclassified by the network with high confidence, as seen in the example in Figure 10.16.

**Figure 10.16** Example of an adversarial attack against a trained convolutional network. The image on the left is classified as a panda with confidence 57.7%. The addition of a small level of a random-looking perturbation (that itself is classified as a nematode with confidence 8.2%) results in the image on the right, which is classified as a gibbon with confidence 99.3%. [From Goodfellow, Shlens, and Szegedy (2014) with permission.]

<img src="figure-10-16.png" alt="Figure 10-16" width="600" height="170" />


The ability to fool neural networks in this way raises potential security concerns as it creates opportunities for attacking trained classifiers. It might appear that this issue arises from over-fitting, in which a high-capacity model has adapted precisely to the specific image such that small changes in the input produce large changes in the predicted class probabilities. However, it turns out that an image that has been adapted to give a spurious output for a particular trained network can give similarly spurious outputs when fed to other networks (Goodfellow, Shlens, and Szegedy, 2014). Moreover, a similar adversarial result can be obtained with much less flexible linear models. It is even possible to create physical artefacts such that a regular, uncorrupted image of the artefact will give erroneous predictions when presented to a trained neural network, as seen in Figure 10.17. Although these basic kinds of adversarial attacks can be addressed by simple modifications to the network training process, more sophisticated approaches are harder to defeat. Understanding the implications of these results and mitigating their potential pitfalls remain open areas of research.

## 10.3.4 对抗攻击

相对于输入图像像素值变化的梯度，也可以用来构造针对卷积网络的**对抗攻击**（Szegedy *et al.*, 2013）。这些攻击通过对图像进行非常小的修改，小到人类无法察觉，却能使图像被神经网络错误分类。构造对抗图像的一种简单方法称为*快速梯度符号法*（Goodfellow, Shlens, and Szegedy, 2014）。该方法将图像 $\mathbf{x}$ 中的每个像素值改变一个固定量 $\epsilon$，其符号由误差函数 $E(\mathbf{x}, t)$ 相对于像素值的梯度决定。由此得到修改后的图像定义为

$$
\mathbf{x}' = \mathbf{x} + \epsilon \operatorname{sign}(\nabla_{\mathbf{x}} E(\mathbf{x}, t)). \tag{10.11}
$$

这里 $t$ 是 $\mathbf{x}$ 的真实标签，误差 $E(\mathbf{x}, t)$ 可以是例如 $\mathbf{x}$ 的负对数似然。所需梯度可以通过反向传播高效计算。在神经网络的常规训练中，网络参数被调整以最小化该误差，而（10.11）所定义的修改则是在保持训练好的网络参数不变的情况下改变图像，以增大误差。通过保持 $\epsilon$ 很小，我们确保图像的变化对人类肉眼不可察觉。值得注意的是，这可以产生被网络以高置信度错误分类的图像，如图 10.16 中的示例所示。

**图 10.16** 针对训练好的卷积网络的对抗攻击示例。左侧图像被分类为熊猫，置信度为 57.7%。加入少量看起来随机的扰动（该扰动本身被分类为线虫，置信度为 8.2%）后得到右侧图像，它被分类为长臂猿，置信度为 99.3%。[经 Goodfellow, Shlens, and Szegedy (2014) 许可转载。]

<img src="figure-10-16.png" alt="Figure 10-16" width="600" height="170" />

以这种方式欺骗神经网络的能力引发了潜在的安全隐患，因为它为攻击训练好的分类器创造了机会。表面上看，这个问题似乎源于过拟合，即高容量模型精确地适应了特定图像，以至于输入的微小变化会导致预测类别概率的巨大变化。然而，事实证明，一个针对某个特定训练网络被调整以产生虚假输出的图像，在输入到其他网络时也能产生类似的虚假输出（Goodfellow, Shlens, and Szegedy, 2014）。此外，即使使用灵活性低得多的线性模型，也能获得类似的对抗结果。甚至有可能构造出物理制品，使得该制品的常规、未受损坏的图像在呈现给训练好的神经网络时会产生错误预测，如图 10.17 所示。尽管这些基本类型的对抗攻击可以通过对网络训练过程进行简单修改来应对，但更复杂的方法更难被击败。理解这些结果的含义并减轻其潜在缺陷，仍然是开放的研究领域。

## 重点总结

1. **对抗攻击的定义**  
   对抗攻击是指对图像进行微小、人类不可察觉的修改，使神经网络将其错误分类。

2. **快速梯度符号法**  
   式（10.11）给出了快速梯度符号法的核心思想：
   - 计算误差函数 $E(\mathbf{x}, t)$ 对输入像素的梯度；
   - 取梯度的符号；
   - 沿该符号方向以固定步长 $\epsilon$ 修改每个像素；
   - 从而增大误差，使网络误分类。

3. **梯度可通过反向传播计算**  
   与训练时调整网络参数相反，对抗攻击保持网络参数固定，只修改输入图像。

4. **对抗样本具有高置信度误分类**  
   即使修改很小、肉眼不可见，网络仍可能以很高置信度给出错误类别。

5. **对抗攻击的普遍性**  
   - 不局限于某个特定网络，同一对抗图像可欺骗多个网络；
   - 线性模型也能产生类似对抗结果；
   - 可构造物理制品，使真实拍摄的图像被误分类。

6. **安全影响与研究方向**  
   对抗攻击带来安全隐患；简单修改训练过程可缓解基本攻击，但更复杂的方法难以防御，仍是开放研究领域。

## 难点总结

1. **理解式（10.11）的符号与方向**  
   需要理解 $\operatorname{sign}(\nabla_{\mathbf{x}} E)$ 表示沿使误差增大的方向修改像素，而 $\epsilon$ 控制修改幅度。

2. **训练与攻击的区别**  
   训练时调整网络参数以最小化误差；攻击时固定网络参数，调整输入图像以最大化误差。

3. **为什么小扰动会导致高置信度误分类**  
   这与高维输入空间中的线性行为、梯度方向以及模型决策边界有关，理解起来较抽象。

4. **对抗样本的迁移性**  
   针对一个网络构造的对抗样本能欺骗其他网络，说明这不是单纯过拟合，而是更普遍的现象。

5. **物理对抗攻击**  
   图 10.17 表明对抗攻击不仅存在于数字图像中，还能体现在物理物体上，这增加了理解和防御的难度。

6. **防御的困难**  
   简单修改训练过程可应对基本攻击，但更复杂的对抗方法难以击败，说明该问题尚未完全解决。
