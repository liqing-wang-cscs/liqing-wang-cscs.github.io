# Python 实验讲解稿：卷积神经网络核心概念

## 开场

大家好，这个实验用最少的 Python 代码，帮助初学者直观理解卷积神经网络里的几个核心概念：

- 卷积
- 边缘检测
- 平移等变性
- 最大池化
- 多通道卷积
- 1×1 卷积

我们只用 `numpy` 和 `matplotlib`，不需要任何深度学习框架。

---

## 第一段：构造图像

<!-- ```python
img = np.array([
    [10, 10, 10, 10, 10, 10],
    ...
], dtype=float)

img[:, 3:] = 100
``` -->

这里我们构造了一个 6×6 的灰度图像。

左半边像素值是 10，右半边是 100。

这样一来，中间就形成了一条明显的**垂直边缘**。

这一步的目的是：先有一个简单、可控的输入，方便后面观察卷积的效果。

---

## 第二段：二维卷积函数

<!-- ```python
def conv2d(image, kernel, stride=1, padding=0):
    ...
``` -->

这是整个实验的核心函数。

它做的事情就是：

- 把滤波器放在图像上
- 对应位置相乘再求和
- 然后按步长滑动
- 最后得到一张新的特征图

这里同时支持：

- `stride`：步长
- `padding`：填充

这就是卷积层最基本的运算过程。

---

## 第三段：垂直边缘检测

<!-- ```python
vertical_kernel = np.array([
    [-1, 0, 1],
    [-1, 0, 1],
    [-1, 0, 1],
])

vertical_map = conv2d(img, vertical_kernel)
``` -->

这个滤波器在水平方向求差值。

左边是负的，右边是正的。

所以当图像中出现**从左到右的强度变化**时，也就是垂直边缘，它会产生很强的响应。

运行后你会看到，特征图在中间边缘处出现明显的正负值。

---

## 第四段：水平边缘检测

<!-- ```python
horizontal_kernel = np.array([
    [-1, -1, -1],
    [ 0,  0,  0],
    [ 1,  1,  1],
])

horizontal_map = conv2d(img, horizontal_kernel)
``` -->

这个滤波器是上面那个的转置。

它在垂直方向求差值，用来检测**水平边缘**。

因为我们的图像只有垂直边缘，所以水平边缘的结果几乎全是零。

这一步说明：不同的滤波器，检测不同的特征。

---

## 第五段：平移等变性

<!-- ```python
img_shifted = np.roll(img, shift=1, axis=1)
vertical_map_shifted = conv2d(img_shifted, vertical_kernel)
``` -->

我们把图像向右平移一个像素，再做同样的垂直边缘卷积。

你会发现：特征图也整体向右平移了一个像素。

这就是**平移等变性**。

意思是：输入平移，输出也对应平移。

这正是卷积层天然具备的性质。

---

## 第六段：最大池化

<!-- ```python
def max_pool2d(image, size=2, stride=2):
    ...

pooled = max_pool2d(vertical_map, size=2, stride=2)
``` -->

池化没有学习参数。

这里我们用 2×2 的区域取最大值，步长也是 2。

效果是：

- 特征图变小了
- 但仍然保留了“有没有边缘”的信息
- 对小幅平移不再敏感

这就是**局部平移不变性**。

---

## 第七段：多通道卷积

<!-- ```python
img_rgb = np.stack([img, img * 0.5, img * 1.5], axis=2)

kernel_rgb = np.stack([
    vertical_kernel,
    vertical_kernel * 0.5,
    vertical_kernel * 1.5,
], axis=2)

multi_map = conv2d_multichannel(img_rgb, kernel_rgb)
``` -->

这里我们模拟了一个 RGB 三通道图像。

每个通道都有自己的滤波器。

卷积时，三个通道分别计算，最后再相加。

这就是彩色图像卷积的基本做法。

---

## 第八段：1×1 卷积

<!-- ```python
weights_1x1 = np.array([0.2, 0.3, 0.5])
out_1x1 = conv1x1(img_rgb, weights_1x1)
``` -->

1×1 卷积的滤波器只有一个像素。

它不改变空间尺寸，只对通道方向做加权求和。

常用来：

- 改变通道数
- 降低通道数
- 融合不同通道的信息
