## 10.2. Convolutional Filters

### P1

One motivation for the introduction of convolutional networks is that for image data, which is the modality for which CNNs were designed, a standard fully-connected architecture would require vast numbers of parameters due to the high-dimensional nature of images. 

To see this, consider a colour image with $10^3 \times 10^3$ pixels, each with three values corresponding to red, green, and blue intensities. 

If the first hidden layer of the network has, say, 1,000 hidden units, then we already have $3 \times 10^9$ weights in the first layer. 

Furthermore, such a network would have to learn any invariances and equivariances by example, which would require huge data sets. 

By designing an architecture that incorporates our inductive bias about the structure of images, we can reduce the data set requirements dramatically and also improve generalization with respect to symmetries in the image space.

---

### P2

To exploit the two-dimensional structure of image data to create inductive biases, we can use four interrelated concepts: hierarchy, locality, equivariance, and invariance. 

Consider the task of detecting faces in images. 

There is a natural hierarchical structure because one image may contain several faces, and each face includes elements such as eyes, and each eye has structure such as an iris, which itself has structure such as edges. 

At the lowest level of the hierarchy, a node in a neural network could detect the presence of a feature such as an edge using information that is *local* to a small region of an image, and therefore it would only need to see a small subset of the image pixels. 

More complex structures further up the hierarchy can be detected by composing multiple features found at previous levels. 

A key point, however, is that although we want to build the general concept of hierarchy into the model, we want the details of the hierarchy, including the type of features extracted at each level, to be learned from data, not hard-coded. 

Hierarchical models fit naturally within the deep learning framework, which already allows very complex concepts to be extracted from raw data through a succession of, possibly very many, ‘layers’ of processing, in which the whole system is trained end-to-end.

## 10.2. 卷积滤波器

### 第1段：全连接网络面对图像的高维参数灾难

引入卷积网络的一个动因在于，对于CNN所针对的图像数据模态，标准的全连接架构会因为图像的高维特性而需要极其庞大的参数数量。

为了看清这一点，考虑一张具有 $10^3 \times 10^3$ 像素的彩色图像，每个像素对应红、绿、蓝三个强度值。

如果网络的第一个隐藏层有，比方说，1,000个隐藏单元，那么第一层就已经有 $3 \times 10^9$ 个权重。

此外，这样的网络必须通过样本来学习任何不变性和等变性，这将需要极其庞大的数据集。

通过设计一种架构，将我们对图像结构的归纳偏置融入其中，我们就可以大幅降低数据集需求，并同时改善关于图像空间对称性的泛化能力。


**重点难点**  

- 核心在于量化全连接层的参数爆炸问题（$3 \times 10^9$ 权重），这是理解CNN必要性的直接数学动机。
  
- 难点是理解“通过例子学习对称性”的低效性，以及“将归纳偏置编码进架构”如何同时减少参数和数据需求。

---

### 第2段：层级性、局部性、等变性与不变性

为了利用图像数据的二维结构来创建归纳偏置，我们可以使用四个相互关联的概念：**层级性**、**局部性**、**等变性**和**不变性**。

考虑在图像中检测人脸的任务。

存在一种自然的层级结构，因为一幅图像可能包含多张人脸，每张人脸包含如眼睛等元素，每只眼睛又具有如虹膜这样的结构，而虹膜本身又具有如边缘这样的结构。

在层级的最底层，神经网络中的一个节点可以利用某一图像小区域的**局部**信息来检测如边缘这样的特征是否存在，因此它只需要看到图像像素的一小部分。

更复杂的高层结构可以通过组合前一层发现的多个特征来检测。

然而，关键的一点是，虽然我们希望将层级性的通用概念构建到模型中，但我们希望层级的细节——包括每一层提取的特征类型——是从数据中学习的，而不是硬编码的。

层级模型天然适合深度学习框架，该框架已经允许通过一连串（可能非常多）的处理“层”从原始数据中提取非常复杂的概念，而整个系统是端到端训练的。


**重点难点**  

- 提出了CNN设计的四大支柱概念，其中“层级性”和“局部性”是结构基础，“等变性”和“不变性”是目标属性。
  
- 难点在于区分“硬编码层级细节”与“学习层级细节”的区别，以及理解“端到端训练”如何让高层特征自动从底层特征组合中涌现。
