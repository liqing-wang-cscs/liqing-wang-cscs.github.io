## 关键概念
### 2.1 概率基础
- [[不确定性#不确定性分类|不确定性分类]]
  - [[认知不确定性|认知不确定性（epistemic）]]：源于数据有限，可通过更多数据降低
  - [[随机不确定性|随机不确定性（aleatoric）]]：源于信息不完全，可通过多源数据降低
- [[概率规则#和规则|和规则]]：$p(X) = \sum_Y p(X,Y)$（离散）或$p(X) = \int p(X,Y)dY$（连续）
- [[概率规则#积规则|积规则]]：$p(X,Y) = p(Y|X)p(X)$
- [[贝叶斯定理|贝叶斯定理]]：$p(Y|X) = \frac{p(X|Y)p(Y)}{p(X)}$
  - [[先验概率|先验概率]]：观测数据前的概率
  - [[后验概率|后验概率]]：观测数据后的概率
  - [[似然函数|似然函数]]：给定Y时X的概率

### 2.2 概率分布
- [[离散分布|离散分布]]：适用于离散随机变量（如伯努利、二项分布）
- [[连续分布|连续分布]]：适用于连续随机变量
  - [[高斯分布|高斯分布]]：$p(x|\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$
  - [[均匀分布|均匀分布]]：区间内概率恒定
  - [[拉普拉斯分布|拉普拉斯分布]]：$p(x|\mu,\gamma) = \frac{1}{2\gamma}exp\left(-\frac{|x-\mu|}{\gamma}\right)$
- [[分布特性|分布特性]]
  - [[期望|期望]]：均值，反映中心趋势
  - [[方差|方差]]：$var[x] = \mathbb{E}[x^2] - (\mathbb{E}[x])^2$，反映离散程度
  - [[协方差|协方差]]：衡量变量间线性相关程度

### 2.3 信息论
- [[熵|熵]]：不确定性的度量
  - [[离散熵|离散熵]]：$H[x] = -\sum_x p(x)log_2 p(x)$
  - [[微分熵|微分熵（连续）]]：$H[x] = -\int p(x)ln p(x)dx$
- [[相对熵|相对熵（KL散度）]]：$KL(p\|q) = -\int p(x)ln\frac{q(x)}{p(x)}dx$，衡量两分布差异
- [[互信息|互信息]]：$I[x,y] = KL(p(x,y)\|p(x)p(y))$，衡量变量间共享信息

### 2.4 参数估计
- [[最大似然估计|最大似然估计（ML）]]：找参数使观测数据概率最大
  - [[高斯均值ML估计|高斯均值ML估计]]：$\mu_{ML} = \frac{1}{N}\sum_{n=1}^N x_n$（无偏）
  - [[高斯方差ML估计|高斯方差ML估计]]：$\sigma_{ML}^2 = \frac{1}{N}\sum_{n=1}^N (x_n-\mu_{ML})^2$（有偏）
- [[贝叶斯估计|贝叶斯估计]]：结合先验概率与似然函数，输出参数后验分布

## 概念关系
- [[贝叶斯定理]] → [[概率规则|和规则/积规则]]：由和规则、积规则推导得出
- [[KL散度]] → [[熵]]：KL散度是两分布熵的差值延伸
- [[最大似然估计]] → [[过拟合]]：仅用ML易因模型复杂度过高导致过拟合
- [[正则化]] → [[贝叶斯估计]]：正则化等价于贝叶斯估计中的先验概率
