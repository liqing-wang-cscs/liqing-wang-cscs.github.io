## 关键概念
### 3.1 离散分布
- [[伯努利分布|伯努利分布]]：描述二元结果（如硬币正反面）
  - [[概率质量函数#伯努利|概率质量函数]]：$Bern(x|\mu) = \mu^x(1-\mu)^{1-x}$
  - 均值：$\mathbb{E}[x] = \mu$，方差：$var[x] = \mu(1-\mu)$
- [[二项分布|二项分布]]：描述N次伯努利试验的成功次数m
  - [[概率质量函数#二项|概率质量函数]]：$Bin(m|N,\mu) = \binom{N}{m}\mu^m(1-\mu)^{N-m}$
  - 均值：$\mathbb{E}[m] = N\mu$，方差：$var[m] = N\mu(1-\mu)$
- [[多项式分布|多项式分布]]：伯努利分布的多类别扩展（1-of-K编码）
  - [[概率质量函数#多项式|概率质量函数]]：$p(x|\mu) = \prod_{k=1}^K \mu_k^{x_k}$

### 3.2 连续分布
- [[多元高斯分布|多元高斯分布]]：D维连续变量的高斯分布
  - [[概率密度函数#高斯|概率密度函数]]：$\mathcal{N}(x|\mu,\sum) = \frac{1}{(2\pi)^{D/2}|\sum|^{1/2}}exp\left(-\frac{1}{2}(x-\mu)^T\sum^{-1}(x-\mu)\right)$
  - 特性：边际分布、条件分布仍为高斯分布
  - [[协方差矩阵|协方差矩阵]]：控制分布形状，正定时分布有效
- [[混合高斯分布|混合高斯分布]]：多个高斯分布的线性组合
  - [[概率密度函数#混合高斯|概率密度函数]]：$p(x) = \sum_{k=1}^K \pi_k \mathcal{N}(x|\mu_k,\sum_k)$
  - [[混合系数|混合系数]]：满足$0\leq\pi_k\leq1$且$\sum_{k=1}^K\pi_k=1$
- [[冯·米塞斯分布|冯·米塞斯分布]]：周期变量的高斯类似分布
  - [[概率密度函数#冯·米塞斯|概率密度函数]]：$p(\theta|\theta_0,m) = \frac{1}{2\pi I_0(m)}exp\left(m cos(\theta-\theta_0)\right)$

### 3.3 指数族分布
- [[指数族分布|定义]]：$p(x|\eta) = h(x)g(\eta)exp\left(\eta^T u(x)\right)$
  - [[自然参数|自然参数]]：决定分布形状
  - [[充分统计量|充分统计量]]：数据的核心摘要（如伯努利分布中$u(x)=x$）
- 包含分布：伯努利、二项、高斯、多项式等

### 3.4 非参数密度估计
- [[直方图法|直方图法]]：将数据划分为bins，密度为bin内点数/（总点数×bin宽度）
  - 缺陷：高维下维度灾难，存在人工不连续性
- [[核密度估计|核密度估计]]：$p(x) = \frac{1}{N}\sum_{n=1}^N \frac{1}{h^D}k\left(\frac{x-x_n}{h}\right)$
  - [[核函数|核函数]]：满足非负、归一化（如高斯核）
  - [[带宽|带宽h]]：控制平滑程度
- [[K近邻估计|K近邻估计]]：固定K，找包含K个数据点的最小球体，密度$p(x) = \frac{K}{NV}$
  - 特性：非参数，无需假设分布形式

## 概念关系
- [[多项式分布]] → [[伯努利分布]]：K=2时退化为伯努利分布
- [[混合高斯分布]] → [[高斯分布]]：由多个高斯分布线性组合而成
- [[指数族分布]] → [[常用分布|常用分布]]：伯努利、高斯等均属于指数族
- [[核密度估计]] → [[直方图法]]：核密度是直方图的平滑扩展，避免不连续性
