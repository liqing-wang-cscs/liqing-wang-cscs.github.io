## 关键概念
### 4.1 线性回归模型
- [[线性回归#基础形式|基础形式]]：$y(x,w) = w_0 + \sum_{j=1}^{M-1}w_j\phi_j(x) = w^T\phi(x)$
  - [[基函数|基函数]]：将输入映射到特征空间（如多项式、高斯、sigmoid）
  - [[权重向量|权重向量]]：可学习参数，$\phi_0(x)=1$对应偏置项$w_0$
- [[设计矩阵|设计矩阵]]：$N×M$矩阵，元素$\Phi_{nj} = \phi_j(x_n)$

### 4.2 模型优化
- [[最小二乘误差|最小二乘误差]]：$E(w) = \frac{1}{2}\sum_{n=1}^N (y(x_n,w)-t_n)^2$
  - [[闭式解|闭式解]]：$w_{ML} = (\Phi^T\Phi)^{-1}\Phi^T t$（Moore-Penrose伪逆）
- [[正则化最小二乘|正则化最小二乘]]：$E(w) = \frac{1}{2}\sum_{n=1}^N (y(x_n,w)-t_n)^2 + \frac{\lambda}{2}w^T w$
  - [[闭式解#正则化|闭式解]]：$w = (\lambda I + \Phi^T\Phi)^{-1}\Phi^T t$
  - [[正则化系数|正则化系数λ]]：控制正则化强度

### 4.3 学习范式
- [[批量学习|批量学习]]：一次性使用所有训练数据优化参数
- [[序列学习|序列学习（在线学习）]]：逐数据点更新参数，$w^{(\tau+1)} = w^{(\tau)} + \eta(t_n - w^{(\tau)T}\phi_n)\phi_n$
  - [[学习率|学习率η]]：控制每次更新幅度

### 4.4 决策理论
- [[损失函数|损失函数]]：量化预测误差
  - [[平方损失|平方损失]]：$L(t,f(x)) = (f(x)-t)^2$，最优预测为条件均值$\mathbb{E}[t|x]$
  - [[闵可夫斯基损失|闵可夫斯基损失]]：$L_q(t,f(x)) = |f(x)-t|^q$，q=1对应中位数，q→0对应众数
- [[期望损失|期望损失]]：$\mathbb{E}[L] = \iint L(t,f(x))p(x,t)dxdt$，目标是最小化期望损失

### 4.5 偏差-方差权衡
- [[偏差|偏差]]：$(\mathbb{E}_D[f(x;D)] - h(x))^2$，模型平均预测与真实函数的差异
- [[方差|方差]]：$\mathbb{E}_D[(f(x;D) - \mathbb{E}_D[f(x;D)])^2]$，模型预测的波动程度
- [[关系|关系]]：期望损失 = 偏差² + 方差 + 噪声（不可约）
  - [[复杂模型|复杂模型]]：低偏差、高方差
  - [[简单模型|简单模型]]：高偏差、低方差

## 概念关系
- [[线性回归]] → [[单层神经网络]]：线性回归是仅含输出层的单层网络
- [[正则化]] → [[方差]]：正则化通过降低模型复杂度减少方差
- [[基函数]] → [[特征空间]]：基函数将原始输入映射到高维特征空间
- [[序列学习]] → [[大数据]]：序列学习适用于无法一次性加载的大数据集
